# v1.0.0 — 首个公开版本

Step Code 的子代理编排可视化面板。终端中运行的 `subagent` / `workflow` 编排,以液态玻璃界面在浏览器中实时呈现。

## 功能

### 编排视图
- 实时编排树:`tool_call` / `tool_update` / `tool_result` 三类事件重建拓扑,节点状态机覆盖 pending / running / done / failed / cancelled。
- 扇出模式按参数形状推断(`chain` / `tasks` / `agent`),不依赖显式 `mode` 字段;模式徽标与任务摘要直接上卡。
- 子代理行内明细(状态、摘要、token 用量),单个编排节点至多渲染 120 张叶子卡。
- 顶栏聚合指标:运行中 / 已完成 / 失败 / 编排数 / token 总消耗。
- 「仅编排」筛选与「折叠已完成」开关;节点详情面板展示概况、进度条、子代理明细与脱敏后的调用参数。

### 对话视图
- 会话历史回放,新开面板不空白;助手回复按 80ms 合帧流式渲染,气泡按 id 复用,不重建列表。
- 贴底滚动策略(距底部不足 72px 自动跟随,否则显示「回到底部」),不打断向上翻阅。
- Enter 发送、Shift+Enter 换行、IME 组合期不劫持回车;agent 忙碌时自动降级 `followUp` 排队。
- 视图切换(编排 ↔ 对话)不卸载 DOM:滚动位置、选中节点、输入框草稿全部保留,240ms `aria-busy` 窗口抑制重复触发。

### API 配置切换
- 多账户 coding Plan 热切换:`registerProvider` 免重启生效,仅覆盖传入字段,模型目录不动。
- 密钥只存网关侧 `~/.stepcode/agent/step-orchestra/profiles.json`(0600,先写 `.tmp` 再 rename 原子落盘);浏览器只收 `keyHint` 掩码投影。
- 凭据失效不主动探测:监听真实流量,401 / 403 时将当前配置标红并给出原因。
- 行内编辑(密钥留空保留原值)、删除(原生 confirm 二次确认)、静态校验(必填项、长度异常标记)。

### Token 用量行
- 对话底部单行指标:`tok/s · 首字 · 输出/生成 · 均值 · 累计 · 上下文占用`;数值仅在响应落地时变化,不轮询。
- 数字双轨制:精确值千分位,累计值紧凑单位;≥75% / ≥92% 整行转琥珀 / 红,并追加「接近上限」/「即将溢出,建议 /compact」。
- 速率由事件到达时间推算,生成窗口 <200ms 或 >1h 的噪声样本不计入滑动平均。

### 液态玻璃界面
- `backdrop-filter` 折射底、142° 白色渐变玻璃体、指针跟随高光、≤4.5° 视差倾斜、空状态 SVG 位移滤镜。
- 性能护栏:rAF 合并指针事件、入场动画 `backwards`、`contain: layout paint`。
- 降级:`@supports not (backdrop-filter)` 转高不透明纯色;`prefers-reduced-motion` 关闭全部动效。

## 架构

| 层 | 职责 |
|---|---|
| TypeScript 扩展 | 宿主事件规范化为 JSONL 写入子进程 stdin,不含业务逻辑 |
| Go 网关(标准库零依赖) | 重建拓扑、维护状态,SSE 推送;反向通道经 stdout 回传 |
| 浏览器面板(零构建) | 全部图形渲染与动效 |

## 安全

- 仅绑定 `127.0.0.1`,端口冲突自动顺延(至多 12 次)。
- 每次运行生成 24 字节随机 token,数据端点均校验,常数时间比较。
- 参数经脱敏:`key` / `token` / `secret` / `password` / `authorization` / `cookie` 等键整值替换,单字符串截断 2048 字符。
- 前端一律 `textContent` 写入宿主数据;不落盘,token 只在扩展内存流转。

## 已知限制

- 真实 agent 事件流未验证(需登录宿主后触发)。
- `registerProvider` 热切换实际生效未验证。
- 扇出仅一层(Step Code 约束);端口固定 47810–47821;接口形状按宿主 0.1.1 实测校准(解析层兼容 0.84.x)。

## 安装

```bash
cd gateway && go build -o ../bin/step-orchestra-gateway .   # Windows 附加 .exe
step install /absolute/path/to/step-orchestra
# 在 Step Code 中执行 /orchestra 获取面板地址
```
