# v1.5.0 — 稳定性、并发正确性与渲染性能修复

v1.0.0 之后的第一批修复,来自一次全量代码审查(性能与交互两类共 26 项发现),全部落地。无破坏性变更,无新功能;升级只需重新构建网关二进制。

## 稳定性

- **超长帧不再杀死网关。** 此前 `bufio.Scanner` 遇到超过 4MB 行上限即永久失效并触发 `os.Exit(0)`,而 400 条 × 20k 字符的会话历史单行可达 ~8MB(中文更高)——打开面板的瞬间就会杀死网关,退出码 0 使扩展误判为正常关闭,旧面板永久 401。现在 stdin 改为手写行读取,超限行按块丢弃并告警;扩展侧同时给历史回放加 150 万字符预算,超限从最旧端裁剪(保底保留最新一条)。
- **EPIPE 不再拖垮宿主。** bridge 为 stdin/stdout/stderr 补齐 `error` 监听。此前网关死亡后的写入会以异步 EPIPE error 事件抛出,try/catch 接不住,可能变成宿主进程内的未捕获异常。
- **崩溃后可恢复。** 网关异常退出时清空过期 `panelUrl` 并把退出码 0 记为异常;重拉成功后自动重放 session 头、对话历史与最近一次 usage,已打开的面板保留全部上下文,`/orchestra` 不再打印失效地址。

## 并发正确性

- **消除快照 data race。** `Snapshot()` 此前交出活节点指针,HTTP/SSE goroutine 在锁外序列化时与 stdin 状态突变并发(按 Go 内存模型属未定义行为)。现在改为锁内值拷贝——节点切片字段均为整体替换,浅拷贝即安全。
- **帧序严格单调。** 序列号分配、序列化、广播合并进同一把锁,消除「seq 6 先于 5 到达」的乱序倒置——此前客户端会把它误判为断档并触发多余重同步。
- **订阅/快照竞窗闭合。** SSE 先订阅后发快照;两步之间广播的帧落入缓冲并随初始帧重放,客户端将 seq ≤ 已见值的帧按陈旧重复丢弃(快照帧无条件重锚 seq,兼容网关重启后计数归零)。

## 渲染性能

- **修复全树闪烁。** `appendChild` 已挂载元素等于摘下重插,会取消并重放 CSS 入场动画:此前每个携带子代理行的进度帧都让整片叶子网格重放 0.34s 动画,每个新节点、筛选切换、重同步都让整棵树闪一遍。现在 `syncLeaves` 仅在卡片不在目标位置时 `insertBefore`,全量重建改为增量有序 diff,存留卡片不再被触碰。
- **更新路径收敛到单个 rAF 队列。** 此前新节点走 rAF、已有节点更新逐 SSE 帧同步执行(每帧附带一次 O(N) 统计);现在结构变更与脏节点集合并帧处理,顶栏统计每显示帧至多重算一次,秒级耗时轮询仅在存在运行中节点时工作。
- **节点详情签名门控。** 选中节点的进度帧不再整块重建面板(含参数 JSON 与最多 200 行子代理列表),内容签名不变即跳过。
- **进度更新合帧。** 扩展层按 `toolCallId` 做 60ms 尾随合帧(进度是全量快照,仅最新帧有意义),`tool_result` 前先冲刷,终态顺序不受影响。
- **节点数软上限。** 网关保留至多 1000 个节点,超限从最旧端淘汰已终结节点(运行中/等待中永不淘汰);此前节点在网关内存、前端数组与 DOM 三处均无限增长。
- **进度环保留过渡。** 环形进度改为原地更新 `stroke-dashoffset`,0.5s 描边过渡不再被整块重建吞掉。

## GPU 成本

- **卡片不再逐张采样背景。** `.node-card` 移除 `backdrop-filter` 与常驻 `will-change: transform`(每卡独立合成层 + 背景模糊采样,是节点多时的主要掉帧来源),底色略提高不透明度保持可读;毛玻璃保留在 topbar 与两块面板。
- **呼吸动画上合成器。** 运行节点的「呼吸」由专用 `.card-glow` 覆盖层的 `opacity` 动画驱动,不再逐帧重绘 `box-shadow`。

## 交互

- **发送即时回显。** 消息发出即插入本地「待达」气泡(半透明),宿主回放对应消息时原位消解(文本匹配优先、FIFO 兜底,兼容宿主展开模板);发送失败时原文回填输入框并显示错误——此前发送后输入框清空,慢宿主看起来像丢消息,失败后原文无处找回。
- **忙碌时可发送。** agent 生成中不再禁用发送按钮:扩展既有的 `followUp` 排队路径从 UI 可达(修复文档承诺与实际行为矛盾),按钮悬停提示「生成中,发送的消息将排队送达」。
- **失效有指引。** SSE 断开 2 秒后探测 `/api/snapshot`,收到 401 即停止无限重连并提示「会话已失效,请重新运行 /orchestra 打开新面板」——此前网关重启换 token 后旧面板永远停在「重连中」,输入框锁死且无任何解释。
- 空状态改按过滤后可见数判定(「仅编排」下不再出现无提示的空白树);移除编排树上的 `aria-live` 防止读屏刷屏;user 消息 fallback id 前后一致,宿主不给 id 时不再产生重复气泡。

## 其他

- 脱敏改两级匹配:`metaKey` / `keyCode` / `author` 不再误伤,`apiKey` / `authorization` / `token` 照常整值替换。
- 短密钥(<24 字符)掩码收紧为前 2 后 2,12 字符密钥不再暴露 2/3 的内容。
- `/healthz` 加鉴权;清理重复的 `formatClock` 定义;`buildContextEntries()` 包裹 try/catch,历史回放失败不再中断 `session_start` 分发。
