# v2.0.0 — 一键启用、性能模式与多轮可靠性验证

V2.0.0 面向两类目标:**让新手用户无需任何命令行即可启用**,以及**在视觉不打折扣的前提下把无谓的性能开销关掉**。无破坏性变更;`profiles.json` 与线协议格式未变,升级只需拉取后重新构建网关(或让扩展/启动器自动完成)。

## 一键启用

- **新增一键启动器 `start.mjs`。** 自动定位网关二进制 → 缺失时用 Go 构建(`-trimpath -ldflags "-s -w"`,产物从约 10 MB 降至约 7 MB)→ 启动网关 → 自动打开浏览器。`--demo` 回放内置场景供零依赖体验,`--build-only` 供 `npm run build` 复用,`--no-open` / `--port N` 可选。启动逻辑按平台拆为可测纯函数。
- **双击入口。** `start.bat`(Windows,自动处理 UTF-8 输出与 Node 缺失提示)与 `start.sh` / `start.command`(macOS / Linux)。新手全流程收敛为:克隆 → 双击 → 看到面板。
- **`npm start` / `npm run demo` / `npm run build` / `npm test`** 四个脚本落地到 package.json。
- **扩展侧自动构建。** `bridge.ts` 发现二进制缺失时,自动在后台调用 Go 构建(每次会话限一次尝试,30 s 冷却,`STEP_ORCHESTRA_AUTOBUILD=0` 可关闭);构建期间事件在内存排队,完成后一次性回放并拉起网关——装好扩展敲 `/orchestra` 即可,不再出现要求手敲构建命令的死胡同。构建失败(含 Go 未安装)给出中英双语、指明一键方案的提示。
- **演示模式** `npm run demo`:不安装 Step Code 也能看到完整面板效果(mock 场景回放 + 保持服务)。

## 性能模式(界面降载)

- **新增 `web/perf.js` 与 topbar「性能」开关。** 开启后:极光背景冻结为静态渐变、全部 `backdrop-filter` 关闭(换用等可读性的不透明渐变)、入场/呼吸/脉冲动画全部停用、`glass.js` 跳过指针追踪(含每次 pointermove 的 `getBoundingClientRect` 与 rAF 写变量)。状态色 rail 与静态描边保留,信息层级不变。
- **自动默认值。** 首次访问且无本地选择时,`prefers-reduced-motion`、≤ 4 逻辑核或 ≤ 4 GB 内存自动进入省电模式;自动默认不落盘,手动切换才写 `localStorage`(`step-orchestra:perf-lite`),换设备不被误伤。
- **后台休眠。** 标签页隐藏时 `html.perf-paused` 暂停极光与呼吸等持续动画,回前台自动恢复——后台挂着的面板不再白烧 GPU/电池。
- 低端设备的判定阈值属于保守估计,用户随时可手动覆盖;该开关不改变任何数据行为。

## 可靠性与测试基建

- **网关状态机单元测试 `gateway/state_test.go`**(`go test`):会话/工具生命周期与耗时、失败终态、1000 节点逐出且运行中永不淘汰、中途附着占位节点、帧序号严格单调、统计聚合,共 6 组。
- **启动器回归 `tools/test-launcher.mjs`**:平台二进制命名、浏览器打开命令、参数解析(含越界端口拒绝)、候选二进制解析,6 项。
- **扩展模块图冒烟 `tools/test-extension-import.mjs`**:整图导入(含 `bridge.ts` / `index.ts`),断言默认导出工厂与 `Bridge` 公共面,`dispose` 幂等。
- **聚合入口 `tools/run-all-tests.mjs`**:go vet → go test → 模块图 → 载荷解析 → 层叠校验 → 启动器 → 端到端,支持 `--rounds N` 多轮浸泡与 `--skip-build`,任一步失败即非零退出;`npm test` 直达。
- 端到端场景维持 mock-feed 33 断言不变,本期未改线协议。

## 验证

- `gofmt` / `go vet` / `go test` 通过。
- `tools/run-all-tests.mjs --rounds 3` **三轮全绿**:mock-feed 33/33、progress 11/11、layers 11/11、launcher 6/6、扩展模块图冒烟、go test 6 组,每轮一致。
- 浏览器手工验证(mock-feed --serve):性能开关切换、`perf-lite` 类生效(背景停止动画、毛玻璃切换为不透明)、后台标签页暂停、刷新后持久化,编排树 / 对话 / 视图切换不受影响。

## 升级

```bash
npm run build        # 或直接 npm start / 双击 start.bat(自动构建)
```

无需迁移配置;`profiles.json` 与事件契约均未变化。完整变更见 V2.0.0 提交。
