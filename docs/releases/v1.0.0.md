## 中文

十二个插件，四十八个版本计划的第一批。本版本只做一件事：把每个插件的 MVP 闭环立起来——命令能跑、守卫能拦、报告能落盘。没有炫技，全是地基。

工程口径：全部插件声明式清单 + 零依赖实现；MCP 型走 Node stdio JSON-RPC（与官方 SDK 协议兼容，规避断网环境 npm install 的不确定性）；外部 CLI（docker/gh/psql）一律带测试缝与降级指引，缺什么给什么指引，不裸报错。

## English

Twelve plugins, first batch of the 48-version plan. This release does exactly one thing: stand up each plugin's MVP loop — commands run, guards block, reports land on disk. No theatrics, all foundation.

Engineering notes: declarative manifests + zero-dependency implementations across the board; MCP servers speak Node stdio JSON-RPC (protocol-compatible with the official SDK, avoiding flaky-network `npm install`); every external CLI (docker/gh/psql) ships with a test seam and a degradation guide — missing tooling yields instructions, never a bare stack trace.
