## 中文

v1.0.0 把闭环立起来了，v1.1.0 解决「闭环之外的质量与覆盖面」：提交更规范（语言/scope/commitlint 联动）、生态更宽（新增四种测试栈、两种审计生态、MCP 化统计）、边界更硬（校验用例从样例走向对抗）。参数不达标不出门。
