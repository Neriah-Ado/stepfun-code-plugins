## 中文

收官版本，进入各自领域的深水区：根因定位（bisect/flaky）、自动化发布（release PR）、多平台（GitLab/Jenkins）、多语言（Python SDK）、多数据库（mysql/sqlite）。每个深水功能都带两条救生索：可脚本化验证 + 真机联调待办（诚实记录在开发元数据中）。
