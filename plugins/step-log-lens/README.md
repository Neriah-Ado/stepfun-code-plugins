# step-log-lens — 本地日志透视

纯声明式插件：把大日志变成「几组错误、几条趋势、一份落盘报告」，喂给模型的永远只是截断样本。

## 它解决什么

排查问题时最贵的是把几万行日志原样丢进对话：token 爆炸，还可能把日志里夹带的凭据一起带出去。本插件先本地聚类、脱敏、截断，再把结论和样本交给模型，完整材料留在项目内的报告文件里。

## 使用

| 命令 | 说明 |
| --- | --- |
| `/log-analyze <文件> [窗口]` | 错误聚类（计数 + 首末时间）、级别分布、时间线；报告落盘 `docs/log-report/` |
| `/log-tail <文件> [--last N] [--grep 关键字]` | 尾部快照 + 关键字过滤，命中过多时只给计数与样本 |

## 安装

```bash
/plugin marketplace add Neriah-Ado/stepcode-plugins
/plugin install step-log-lens
```

## 验证

```bash
node tests/validate.mjs
```

## 边界与限制

- 无时间戳的自由格式日志只有聚类能力，无时间线。
- 做一次性快照，不提供长驻 `tail -f`；持续观察建议 `/cron` 定期调用。
- 聚类以错误码/异常类名/堆栈首帧为键，完全自定义格式的日志归并精度有限。
