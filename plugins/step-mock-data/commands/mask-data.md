## 流程

1. 识别数据中的个人信息字段（列表见 MASK-RULES）。
2. 按规则掩码，保持格式；识别不确定的（姓名）结合上下文标注疑似。
3. 输出掩码结果 + 可逆性声明；`--full` 时全掩码并声明不可逆。
4. 原文永不落盘。

## 输出格式

掩码结果（表格或代码块）→ 识别统计（各类型 N 处）→ 可逆性声明 → 疑似项说明。
