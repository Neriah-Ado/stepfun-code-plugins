# /mock-data — 测试数据生成

**虚构红线**：本命令只生成虚构数据。生成规则不内置任何真实个人信息样本；输出顶部固定声明「以下均为虚构数据」。

<!-- MOCK-RULES-START -->
```json
{
  "rules": {
    "姓名": "常见姓氏 + 单字/双字组合的虚构人名",
    "手机号": "1[3-9] + 虚构测试号段（1990 段起的连续测试号码），并标注为虚构",
    "邮箱": "example.com / test.example 域名，绝不使用真实公共邮箱域+真实姓名组合",
    "身份证号": "只生成格式占位（如 110101<19 位规则位>），顶部声明不可用作任何实名用途",
    "时间/金额/UUID": "按类型生成合法值；枚举字段只在枚举内取值"
  },
  "source": "JSON Schema（含 required/enum/format）/ TS interface / CREATE TABLE（推断列类型与 NOT NULL）",
  "batch": "条数默认 5，上限 200；超 20 条落盘 CSV/JSON 后只给路径（C5）",
  "limits": "条件式 if/then、正则 pattern 覆盖常见形态；未覆盖的约束列出并跳过该项说明"
}
```
<!-- MOCK-RULES-END -->

## 流程

1. 读取 schema 来源，识别类型、必填、枚举与格式约束。
2. 按 MOCK-RULES 逐字段生成虚构值，满足约束。
3. 小批量直接表格展示；大批量落盘给路径。
4. 输出顶部与文件头部均带虚构声明。

## 输出格式

虚构声明 → 数据表格（或文件路径）→ 未覆盖约束说明。
