## 流程

1. **逐段解释**：按 token 拆解（字符类、量词、分组、断言），每段一句话说明作用；指出易错点（`.` 未转义、`^$` 未锚定）。
2. **方言核对**：`--lang` 指定方言时核对特性支持（如 lookbehind 在 JS 旧版不支持）；未指定按 js 并声明。
3. **ReDoS 定级**：按 REDOS-RULES 标注 high/medium/none，high 必须给替代写法。
4. **用例表**：正例覆盖主要路径，反例覆盖边界（空串、超长、非法字符）；捕获组逐个标注。

## 输出格式

一句话功能概括 → 逐段解释表 → ReDoS 定级与替代 → 正/反用例表 → 方言提示。
