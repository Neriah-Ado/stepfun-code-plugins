# /regex-gen — 从样例归纳正则

<!-- GEN-RULES-START -->
```json
{
  "input": "至少 3 个样例，少于 3 个拒绝并说明（归纳无依据）",
  "flow": ["找公共字面量与前缀", "对差异段归纳字符类/量词", "对长度敏感段加锚点或 {m,n}", "合成草案"],
  "report": "草案 → 推断规则逐条 → 正例回代结果 → 未覆盖样例清单（有则列出）",
  "verify": "草案必须附「建议立即运行 /regex-check」提示；未跑复核不得直接入库"
}
```
<!-- GEN-RULES-END -->

## 流程

1. 样例不足 3 个时停止并请用户补充。
2. 按 GEN-RULES 归纳：公共段固化，差异段字符类化，长度波动量词化。
3. 正例全部回代核对；归纳不出的部分显式列出「未覆盖样例」，不用通配 `.*` 糊过去。
4. 结尾固定提示运行 `/regex-check` 复核（含 ReDoS 与方言检查）。

## 输出格式

正则草案（代码块）→ 推断规则表 → 回代结果 → 未覆盖样例 → 复核提示。
