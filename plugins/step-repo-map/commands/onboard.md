# /onboard — 上手路径生成

<!-- ONBOARD-RULES-START -->
```json
{
  "input": "优先读 --map 指定的仓库地图（默认 docs/repo-map.md）；不存在时提示先运行 /repo-map",
  "path": "四段式：① 环境与启动（装什么、跑什么、健康标准）② 代码结构走读（按职责表顺序）③ 第一个安全改动点（热点中测试覆盖较好的模块）④ 深水区（热点高但认知少的模块，后置）",
  "verified": "每步标注 已验证（本会话实际执行过）/ 待验证（基于地图推断）；未跑过的命令绝不标已验证",
  "no_invent": "依赖安装命令只引用仓库实际存在的清单文件（package.json/pyproject/go.mod…），缺失则写 TODO"
}
```
<!-- ONBOARD-RULES-END -->

## 流程

1. 读取仓库地图与根级清单文件。
2. 生成四段式路径，命令与文件路径全部来自仓库实际内容。
3. 逐步标注验证状态；本轮会话未执行的命令一律「待验证」。
4. 落盘 docs/onboard.md（或用户指定路径）。

## 输出格式

四段式路径概要 → 验证状态统计 → 文件路径。
