# /shell-check — 命令风险预检

**零执行红线**：本命令只做静态阅读与分级，被检命令本身在任何情况下都不运行（包括子 shell、`bash -c` 等变体）。

## 流程

1. **解析**：拆解命令为子命令/管道/重定向/变量替换；对脚本路径先读文件再逐行分析，不执行。
2. **逐段解释**：每段用一句话说明「做什么、改了什么、影响哪里」；引用变量时指出未加引号的空格/通配符风险。
3. **定级**：按 RISK-RULES 分级，对照 `skills/dangerous-patterns/SKILL.md` 的模式库逐条匹配。
4. **给替代**：每个 warn/block 至少给一个更安全写法（如 `rm` → 先 `ls` 确认目标、远程脚本 → 下载后人工审阅再运行、force push → `--force-with-lease`）。
5. **边界声明**：输出末尾固定一行：分级是静态分析参考，不能替代人工判断。

## 输出格式

风险等级 + 一句话结论 → 副作用清单（表格：片段/作用/等级）→ 替代写法 → 白名单提示（如命中）→ 边界声明。
