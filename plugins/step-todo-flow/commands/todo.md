## 流程

1. `list`（默认）：按优先级展示未完成条目，标注数量。
2. `add`：解析目标优先级（条目内可写 `!p0` 后缀），追加后展示 diff 确认。
3. `done` / `remove`：按序号定位，展示将变更的行，确认后写盘。
4. 文件被外部改动（重读发现 hash 变化）时提示并基于最新内容重放操作。

## 输出格式

操作结果 → diff → 最终清单（list 视图）。无文件且未加条目时只展示说明。
