## [0.3.0] - 2026-10-23

### 新增

- **强调色预设**：四套生化危机主题配色——绯红（`crimson`，默认）、生化危害绿（`biohazard`）、T-病毒紫（`t-virus`）、保护伞红（`umbrella`），另支持 `custom` 自定义颜色。每套预设通过 OKLab 色彩混合自动派生完整色阶，保持与手工调校的绯红色阶一致的对比度梯度。设置页以色板控件展示，选中态带描边反馈。
- **底色选项**：三种底色方案——`clinical`（实验室白，默认）、`carbon`（碳黑中性灰）、`official`（保留 Harness 原生底色）。通过 `data-rq-base` 属性切换，不影响深浅色模式的正常联动。
- **空白页背景**：空白会话页可选四种背景——`hex`（蜂巢六边形网格）、`scanlines`（扫描线）、`full`（完整开屏底）、`off`（关闭），`random` 每次随机。
- **切回动效**：窗口从后台切回时播放过渡动效——`scan`（链路恢复扫描）、`iris`（六边形光圈）、`glitch`（故障闪切），`random` 每次随机。触发条件可设为 `away`（离开 30 秒后）、`always`（每次切回）或 `hidden`（最小化或隐藏后）。设置页提供「预览切回动效」按钮。
- **设置页分节重构**：新增「外观」分节（界面主题、品牌替换、标志方案、强调色、底色、空白页背景）和「动效」分节（切回动效、切回触发），与原有的「开屏」「文字」分节并列。
- **`/redqueen` 命令扩展**：命令菜单新增强调色和底色选项，可直接通过斜杠命令切换。

### 变更

- **界面主题架构升级**：`theme.css` 从裸 `html body` 选择器改为 `html[data-rq-ui] body` 属性驱动模式，与莱茵生命主题对齐。`<html>` 上的 `data-rq-ui`、`data-rq-accent`、`data-rq-base` 三个属性控制主题启停和配色切换，注入脚本在首帧前设置。
- **`lib/index.js` 注入脚本**：`buildInjections` 新增自执行函数，在 `<html>` 上设置 `data-rq-ui` 属性、`data-rq-accent` / `data-rq-base` 数据属性，以及自定义强调色时的 `--rq-accent-custom` CSS 变量。
- **配置 schema 扩展**：`Config` 和 `resolveConfig` 新增 `accent`、`accentColor`、`base`、`heroBackground`、`resumeEffect`、`resumeTrigger` 六个字段，含枚举校验和颜色格式校验。

## [0.2.0] - 2026-10-18

### 新增

- 四种启动动画轮播（`intro` 配置）：`hive` 蜂巢握手、`scan` 身份扫描、`system` 终端引导、`lockdown` 封锁警报；`random` 每次轮换且不与上次重复。
- 安布雷拉（保护伞）印记开场：八角红白相间的八枚扇形自中心依次点亮；印记与启动动画内容独占同一舞台区，先后登场、互不叠加。同一印记的静态版作为第三种品牌标志 `seal`（保护伞印记）。
- 未来感细节：透视全息地板、贯穿舞台的扫描光带、玻璃质感文字面板与角标、标题辉光、眼睛的全息微闪、`scan` 的雷达扫描与生物计量条。
- 退场衔接重构：`.is-leaving` 下根层透明化、舞台整体下电，四种退场与 `fade` 都以揭示真实主界面收尾，消除结束瞬间的跳变与黑屏。
- 对标莱茵生命主题的工艺升级：进度/链路计量按段缓动并在退场时一次 200ms 收尾；`signal` 退场改为克隆舞台撕裂切片（色差描边 + 分级抖动）；`purge` 退场改为逐格波前清除（正弦参差前沿 + 70ms 字符重掷 + 前沿红色描边格）；`iris` 退场加入聚光灯压暗、锁定脉冲环与核心徽记回弹；顶部状态字随节拍三段切换（REQUESTING → UPLINK OK → READY）；HUD 顺时针逐层点亮（对位标记、样本标签、警戒条）；瓦片改透视 Y 轴翻转并带标题与热格强调；链路计量加入流光与读头；六边形网格缓慢漂移；乱码解码带逐字抖动延迟与未定字灰显；百分比改三位等宽数字。
- 第二轮对标：双轨道环 + 红色卫星缓慢环绕舞台；左下角生物观测镜（十字准星 + 垂直扫描线 + 刻度尺 + 每 600ms 波动的 BIO-SIGN 读数）；样本标签加入确定性条形码与遮蔽条揭示；顶栏中央实时时钟；`iris` 脉冲环升级为六边形；`blast` 防爆门内置 200% 高度的六边形网格层，分缝处网格连续、如真实屏幕表面裂开。
- 幕间硬隔离：印记结束后经 `is-seal-done` 从绘制树整体移除（`display: none`）；欢迎页入场后经 `is-actb` 将第一幕永久隐藏。两个类在退场时依然生效，任何时机跳过或退场，已完成的幕都不会重新出现，两幕永不同屏。
- 新增默认退场 `wipe`（垂帘）：第二幕播完前主界面绝无露出；结束后开屏化作整幅不透明幕布完全遮住客户端，自上而下分八段收起，主界面随幕布依次显现。时间轴新增 `done` 节拍，退场起点强制不早于第二幕完成；节拍整体前移压缩约 20%，默认时长降为 4000ms，退场动画全面缩短。

### 安全

- 品牌 HTML 注入路径加固：`lib/index.js` 新增 `isAllowedBrandMarkup`，对 `lib/brand/*` 的 SVG/HTML 做标签与属性白名单校验；事件属性、`javascript:`/`data:` URL、外部 `url(...)`、实体编码、未知标签或无法解析的标记一律整份丢弃，浏览器端 `dangerouslySetInnerHTML` 回退到官方品牌标志。`scripts/test-host.mjs` 增加白名单回归用例。
- 安装文档补充供应链提示：远程安装源 `github:Neriah-Ado/dsh-resident-theme` 建议 pin 到 release tag 或 commit SHA，避免上游分支更新或 tag 移动改变安装内容；`AGENTS.md` 的 Facts/安装说明同步。
